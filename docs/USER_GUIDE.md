# Demo quick guide

1. Run `run-demo.bat`, or start `python src/app.py` from this folder.
2. Search a word such as `gearbox`, `bracket`, or `Drive Gear`.
3. Switch between BOM and Components search to see workbook matches or part
   matches.
4. Select a result to open its synthetic spreadsheet or drawing.
5. In Components mode, open the use list or revision-impact view to explore
   linked assemblies.

Every record in this demo is synthetic. No company files, network shares, or
production indexes are used.
